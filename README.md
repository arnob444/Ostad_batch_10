# Assignment2

Countries Flag UI - Flutter Responsive App

A Flutter application showcasing a responsive card-based UI displaying country flags. The app adjusts the layout based on screen size: 2 cards per row on mobile (< 768px), 3 cards per row on tablet (768px to 1024px), and 4 cards per row on desktop (> 1024px). Each card includes a flag image, rating, enrollment count, duration, country name, and a "See more" button.

## Features





Responsive design using flutter_screenutil for scalable UI elements.



Grid layout that adapts to different screen sizes.



Card design with flag images, ratings, enrollment stats, and interactive buttons.



Support for multiple country flags (e.g., Bangladesh, France, Germany, Australia, Spain, USA, Italy, Japan).

## Prerequisites





Flutter SDK (latest stable version)



Dart



An IDE like VS Code or Android Studio with Flutter plugin



Basic knowledge of Flutter and Dart
